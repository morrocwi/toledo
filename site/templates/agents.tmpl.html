Using Toledo as an AI agent

Founder rule (2026-09-07): every equation must be looked up in Toledo before it is used. No agent may use an unregistered equation. Call toledo_check (or read the verdict block a code lookup already attaches) before stating, citing, or building on any formula. verdict.usable == true — cite the matched code. A superseded or split code — use the redirect it names. A code that only points to prose — do not present it as a formula. A candidate or ambiguous match — get it confirmed, or escalate to a human; do not guess. Not registered — call toledo_register_proposal and wait for a human registrar; this server never merges a proposal into the registry itself.

A minimal, runnable, stdlib-only example — the founder rule enforced client-side:

#!/usr/bin/env python3
"""Look up a Toledo code before citing it -- the founder rule, enforced client-side."""
import json
import urllib.request

code = "EQ-015/B.01.v1"
mangled = code.replace("/", "__").replace(".", "_").replace("-", "_")
url = f"https://morrocwi.github.io/toledo/v1/entries/{mangled}.json"

with urllib.request.urlopen(url, timeout=10) as resp:
    doc = json.load(resp)

verdict = doc["verdict"]
if verdict["usable"]:
    print(f"cite {doc['entry']['code']}: {doc['entry']['name']}")
else:
    print(f"do not cite ({verdict['verdict']}): {verdict.get('reason', '')}")
    print("call the live MCP server instead -- this static copy is eventually consistent")

Static API: should / should not

  • Use entries/, by-root/, by-domain/, and search-index.json for browsing, corroboration, or an offline mirror.
  • Read manifest.json's generated_at/generated_from_commit before treating an answer from this export as more than "as of that export".
  • Do not gate a founder-rule-sensitive decision on this export alone when a live MCP connection is available — call toledo_check/toledo_get instead.
  • A missing entries/<code>.json file here is not proof a code is unregistered — it may simply predate the last export. Fall back to the live server rather than concluding NOT_REGISTERED.

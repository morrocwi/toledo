# ทะเบียนสมการชี่–ตันเถียน–จักระ–น้ำพุเคลื่อนที่ v1.1

วันที่ 14 ตุลาคม 2569 | สถานะ **ข้อเสนอเพื่อการวิจัย (Dr)** ยังไม่พิสูจน์ว่ามีพลังชี่ไหลจริง

เอกสารนี้เป็นทางเข้ากราฟเต็มที่อยู่ใน `registry/knowledge_graph/` ของทั้ง **Toledo** และ **BIRCA ADMIN 5.0**. ทั้งสองแห่งเก็บ payload ตรงกัน 6 ส่วน พร้อมตัวถอดรหัสตรวจ SHA256 ไม่ใช่เพียงลิงก์หรือภาพกราฟบางส่วน

## หลักคิดกลาง

**ชี่ = การแปรเปลี่ยนสารสนเทศ** ในจักรวาลสารสนเทศที่เรากำหนด; การไหลของน้ำและท่อเป็น **อุปมาเชิงสมการ** สำหรับความหน่วง การกระจายและการประสาน มิใช่คำยืนยันว่าชี่เป็นน้ำหรือสารที่มีการตรวจพบ

ใช้ตัวตั้ง `CAN-003` ของ Toledo: `S[n+1]=F(S[n],u[n],c[n],T[n])`. เวลาเป็น **ลำดับสเต็ป** ก่อน แล้วจึงเชื่อม timestamp ภายหลังจากข้อมูลจริง หากต้องการ

ใช้สมการการไหลที่อยู่ใน Toledo: `RUS-0108` (Bernoulli), `RUS-0109` (Continuity), `RUS-0164` (Hagen–Poiseuille); ไม่สับสนกับกลไกชีววิทยาที่พิสูจน์แล้ว การทดลองเคลื่อนหัวน้ำพุและตัวเลขอัตราการไหลที่เคยคำนวณเป็นเพียงน้ำ/กราฟสมมติ ไม่ใช่การตรวจคน

## แผนที่จีน–อินเดียที่แยกสาย

จีน: `DT-L` (ตันเถียนล่าง), `DT-M` (ตันเถียนกลาง), `DT-U` (ตันเถียนบน) และ `小周天`: แนว `GV/CV` ตามกรอบการฝึกบางสาย (หลังขึ้น–หน้าลง) เป็นวงจร **semantic/practice graph**; อย่านำไปเป็น causal DAG วงปิดในหนึ่งสเต็ป

อินเดีย: `CH-01…CH-07` (จักระเจ็ดระดับตามการเลือกกรอบหนึ่ง) และ `Sushumna` เป็นลำดับตามแนวแกนกลาง ไม่ถือว่าตรงกับวงจีนแม้มีตำแหน่งใกล้เคียง `CV1↔Muladhara`, `CV17↔Anahata`, `EX-HN3↔Ajna`, `GV20↔Sahasrara` เป็นการเทียบตำแหน่งเท่านั้น

- **กลางกระหม่อม `GV20 百會` ↔ ฟ้า:** `symbolically_corresponds_to`, บันทึกฐานะสัญลักษณ์
- **ฝ่าเท้า `KI1 湧泉` ← โลก:** `symbolic_intake_at_foot`, `ROLE:EARTH_INTAKE`, แยก `SITE:KI1-L/R` 2 ข้าง
- **กลางฝ่ามือ `PC8 勞宮` → ส่งออก:** `conceptually_emits_via`, `ROLE:PALM_OUTPUT`, แยก `SITE:PC8-L/R` 2 ข้าง
- **`EX-HN3 印堂` หว่างคิ้ว:** เป็นจุดพิเศษอยู่นอก **361** จุด WHO (ไม่ใช่ 362 จุด) และไม่ใช่ `GV20`
- **`DT-L` บ่อพัก:** ตันเถียนล่างเป็น **บริเวณตามแนวฝึก** ไม่เท่ากับ `CV4`, `CV5` หรือ `CV6` อย่างใดอย่างหนึ่งตายตัว
- **น้ำพุเคลื่อนที่:** เปลี่ยนตำแหน่งโมเดลได้ เช่น `DT-L` ไป `EX-HN3`; ตำแหน่งหนึ่งไม่รับรองความเจ็บป่วยหรือการไหลทางกาย

## สิ่งที่เก็บอยู่ในกราฟจริง

ต้นฉบับ **457 โหนด / 845 ความสัมพันธ์** พร้อม Pinyin/Hanzi และโครงสร้าง 361 จุด คงค่าเดิมทั้งหมด

ฉบับใหม่ **497 โหนด / 959 ความสัมพันธ์**; เพิ่ม 40 โหนด/114 ความสัมพันธ์ ซึ่งรวมจักรวาลฟ้า–โลก–ฝ่ามือ สายจีนและอินเดีย การไหล การเปลี่ยนแปลง และทะเบียนโรค 10 กลุ่ม (ย้อนหลัง ไม่ใช่ผลทำนาย)

DAG แยก **44 โหนด/93 เส้น**; เวลา `n` เป็นลำดับ ไม่ใช่ชั่วโมงหรือวัน; ไม่มีวงย้อนกลับใน DAG

## อ่านกราฟจาก Git

```bash
python -m pip install brotli
python registry/knowledge_graph/decode_qi_v1_1.py --output ./qi_unpacked_v1_1
```

จะได้ JSON กราฟเต็ม, causal DAG และ validation พร้อมตรวจ checksums

**ความหมายของ edge:** ทุกความสัมพันธ์มี `relation` และ `evidence_class`; สัญลักษณ์ `ฟ้า`, `รับโลก`, `ส่งออกฝ่ามือ` เป็นสิ่งที่ผู้ก่อตั้งระบบขอเพิ่ม จึงต้องอ่านเป็น **FOUNDER_DECLARED_SYMBOLISM** ไม่ใช่ตำราจีนทุกสำนักยืนยันหรือมีการวัดพิสูจน์ได้

อย่าปรับดัชนีตำแหน่งตามลำพังให้เป็นคำแนะนำกด/ฝังเข็มเพื่อรักษา ผู้มีอาการปวดศีรษะ หอบ เจ็บหน้าอก หรือผิดปกติอื่นต้องแยกความปลอดภัยทางแพทย์ออกจากสัญลักษณ์ชี่
